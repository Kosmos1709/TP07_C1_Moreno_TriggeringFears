# Mi Juego de Plataformas (Unity Web)

## Descripción

Este es un juego de plataformas desarrollado en Unity para navegador web.

Tu misión es explorar el nivel, sobrevivir a los zombis y encontrar el cofre oculto para completar la aventura.

## Controles

- **A** o **Flecha Izquierda**: Moverse a la izquierda
- **D** o **Flecha Derecha**: Moverse a la derecha
- **Barra Espaciadora**: Saltar
- **Click Izquierdo del Ratón**: Disparar el arma

## Objetivo

- Encontrar el cofre para completar el nivel.
- Evitar a los zombis o eliminarlos usando tu arma.
- Sobrevivir hasta llegar al final de la aventura.

## Características

- Juego de plataformas 2D.
- Combate a distancia contra zombis.
- Nivel único diseñado para una experiencia rápida y entretenida.
- Disponible para jugar directamente desde el navegador.

## Duración

El juego está diseñado como una experiencia corta de un solo nivel.
